# AI Usage Disclosure

AI tools, including ChatGPT, were used as development assistance during this project.

## Areas Where AI Assistance Was Used

1. **Project Planning**
   - Understanding the assignment requirements.
   - Planning the backend, frontend, and database structure.
   - Discussing admission workflows and business rules.

2. **Backend Development**
   - Understanding ASP.NET Core and Entity Framework Core concepts.
   - Discussing seat reservation, hold expiration, and concurrency handling.
   - Troubleshooting backend configuration and Docker build issues.

3. **Frontend Development**
   - Assistance with React and TypeScript implementation.
   - Understanding frontend-to-backend API integration.

4. **Testing**
   - Assistance in designing API integration test scenarios.
   - Reviewing test cases for class retrieval, invalid class creation, and concurrent seat reservations.

5. **Documentation and Deployment**
   - Assistance with Dockerfile and Docker Compose configuration.
   - Preparing project assumptions and documentation.

## Developer Responsibility

- AI-generated suggestions were reviewed and adapted during development.
- The developer is responsible for understanding, reviewing, and validating the submitted implementation.
- Automated tests and Docker-based application checks were performed to verify functionality.
- AI assistance was used as a supporting tool and does not replace developer responsibility.
